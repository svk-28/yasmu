## Watchdog

A utility for monitoring system integrity. And for web monitoring of websites availability.

* Runing process
* Users
* Listen ports
* Network connections
* Cron (crontab) files
* URL available

## Notifaction

* Email (smtp sending)
* Matrix
* Webhook
